# Chuzzy's Neovim Config

My Neovim plugins and bindings, configured with lazy.nvim.

## Language Servers
So far, this config depends on the following language servers:

* `ts_ls` (TypeScript)
* `tailwindcss`

## Installation

### Windows
Clone the repo into `$env:LOCALAPPDATA`.

Install Scoop, then run:
```
scoop bucket add extras
scoop install make lazygit
```
